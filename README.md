# 馬拉松跑者 3D 跳躍閃避

實況野球 Q 版風格的 3D 馬拉松小遊戲（Three.js），挑戰 42.195K 全馬。

## 玩法
- ⬆️ **跳躍**（空白鍵／↑）：越過三角錐、欄架，可二段跳
- ⬇️ **滑行**（↓／S）：鑽過充氣拱門、加油布條；空中按會快速落地
- 🛡️ **護盾**：每 30～40 秒出現，可擋一次碰撞（連擊歸零）
- 🔥 **連擊**：每連續閃避 5 次倍率 +0.5，最高 ×3，所有得分都會加乘
- ⛰️ **坡道**：上坡 −20%、下坡 +20%，前方有看板預告
- 🥤 每 10K 補給站、📣 路邊加油團、📍 每公里公里牌顯示配速

## 賽道
約 5 分鐘跑完全馬（1.0x 配速 ≈ 3:30 完賽），共 7 段場景，每換一段升一級：
起跑區 → 河濱自行車道 → 市區街道 → 黃昏 → 夜晚 → 撞牆期 → 終點衝刺。
完賽後可選擇繼續跑「超馬模式」。

## 音樂
原創 8-bit 背景音樂由 Web Audio 即時合成（無音樂檔），每段場景一首，節奏隨等級與坡道變化。

## 線上排行榜
開跑前輸入姓名（會印在號碼布上），結束或完賽後顯示前 10 名（每人取最佳一次，依分數排名）。
成績存在 Apps Script 自動建立的「馬拉松跑者排行榜」Google 試算表。
GitHub Pages 版需在 `index.html` 的 `LEADERBOARD_URL` 填入 Apps Script 的 `/exec` 網址才會共用排行榜。

## 部署
- GitHub Pages：`index.html`
- Google Apps Script：`apps-script/Code.gs` + `apps-script/Index.html`
